What is an Operating System (OS)?
---------------------------------
--> An Operating System (OS) is software that acts as a mediator between the user and the computer hardware.

--> It allows users to interact with computers and run the programs/apps.

--> Without an OS, we cannot use any computer system.

--> It provides an environment (platform) for users to operate and manage hardware and software resources

Types of Operating Systems in the market
=========================================
Common examples include:

Windows

Linux

macOs

Android

iOS
..
..
Windows operating system:
========================
-> Primarily a single-user OS

-> Commercial OS - requires paid licenses

-> Lower built-in security - anti-virus software is often necessary

-> Best suited for personal or home use such as:

 Playing Games
 
 Watching Movies
 
 Internet browsing

 Storing files
 
 Attending online classes

Note : Windows is not recommended for enterprise-level operations like application deployment or server hosting

======================
Linux Operating System
======================

-> Free, Open source and community developed

-> Supports multi-user environment

-> Offers high security

-> CLI-Based (Command Line Interface), though some distros have GUIs

Highly recommended for:

Servers

Application Deployment

Infrastructure Setup

Note : 💡 In real-time IT environments, Linux is the OS of choice for infrastructure and DevOps operations.

📜 History of Linux
=======================
Created by Linus Torvalds

Initially used UNIX OS, but faced limitations and his feedback was not accepted

He discovered Minix OS, which aligned more closely with his ideas

Linus modified Minix and created Linux

Name Origin:
Lin(us) + Min(ux) = Linux

Linux Distributions (Flavors)
=============================

After Linux was released as open source, many companies downloaded the source code and customized it to create their own versions, known as Linux Distributions.

🔹 Popular Linux Distros:

-> CentOS

-> Ubuntu

-> Amazon Linux

-> Red Hat Enterprise Linux (RHEL)

There are 200+ Linux Distributions available today

Linux Commands
==============

$ clear --> To clear our screen

$ mkdir telusko --> create a folder/directory named telusko

$ cd telusko --> changing our current directory to telusko --> to move or go inside telusko directory

$ cd .. --> to come out of the directory

$ pwd --> To check our current directory/folder
/home/ec2-user/telusko

$ rmdir telusko --> it removes/deletes directory by name telusko (It must be an empty directory)

$ rm -rf <directory-name>

$ rm -rf finishers --> To delete/remove directory which is not empty (directory which has some files in it)


---------------------------------------------------
$ ls --> display files present in current working directory ( one beside the other)

$ ls -l --> display files in current working directory in alphabetical order one below the other with file permissions info

$ ls -lr --> display files in current working directory in reverse alphabetical order(z-a) one below the other with file permissions info

$ ls -lt --> display files in current working directory with latest file create on top ( time based order )

$ ls -ltr --> display files in current working directory with oldest file create on top ( time based order )

------------------------------------------------

$ rm <file-name> -> it will remove/delete file 

$ rm alien.txt --> it will delete file named alien

$ rm *.txt --> it will remove/delete all files with extension .txt

$ rm a*.txt --> it will delete all files names starting with a and with .txt extension

Text Editors in Linux
=====================

==> vi (visual editor) ==> it is a default editor in Linux

==> Using 'vi' command we can create new files and we can modify, add, update the existing file data.

==> vi command have 3 modes
1) command mode
===============
=> We can just open file and navigate pr see the content, we cannot edit or modify or add content in this mode

$ vi <file-name>
it could be existing file or a new file and extension could be anything (.txt, .yml, .tf , .py ......)

$ vi alien.txt 
if there is fine by name alien already exist then it will open that file or else it will create a new file

2)Insert Mode
==============
=> To edit the file or to add the content into the file (press i in keyboard to get into insert mode)

3) esc mode
============
=> to come out of the file or to exit the file (press esc in keyboard)
:wq => To save changes we have made in the file and close file
:q! => To close the file without saving the changes

SED command
============

==> SED --> stream editor

==> SED is used to process the data (substitute, delete, insert ,....)

==> SED is very powerful command in Linux using which we can perform operations on the file without opening it

$ sed 's/AWS/AZURE/' aws.txt  (aws.txt is just a file)
Replace first occurrence of  AWS with AZURE in file without saving changes in the original file

$ sed -i 's/AWS/AZURE/' aws.txt
Replace first occurrence of  AWS with AZURE in file and save changes in the original file

$ sed -i 's/AWS/AZURE/g' aws.txt
Replace all occurrence of AWS with AZURE in file named aws.txt

$ sed -i '5d' aws.txt
Delete 5th line from file aws.txt

$ sed -i '$d' aws.txt
Delete last line from file aws.txt

$ sed -i '/AWS/d' aws.txt
Delete all lines from aws.txt file which has 'AWS' word in it

$ sed -n '2,4p' aws.txt
Print the data from line number 2 to 4 from a file aws.txt

$ sed -i '5i\ ai making ppl to learn cloud' aws.txt
Insert Data "ai making ppl to learn cloud" before 5th line in file named aws.txt and save the changes in it


$ sed '5i\ ai making ppl to learn cloud' aws.txt
Insert Data "ai making ppl to learn cloud" before 5th line in file named aws.txt and it doesn't change the original file


$ sed -i '$a\I love or Hate Linux I must learn' aws.txt
Add the data after the last line

================
USER Groups
================

==> A user group in Linux is a collection of user accounts that share the same permissions for accessing files, directories, or system resources.

==> When we create user in Linux , for every user one group also be created with a given username

To display user belong to which group

$ id Suraj  
uid=1003(Suraj) gid=1003(Suraj) groups=1003(Suraj)

(Suraj is a new user account)

==> Creating a new user group
$ sudo groupadd <group-name>
$ sudo groupadd telusko

==> Adding user to a group

$ sudo usermod -aG telusko Suraj  ==> adding Suraj to telusko user group

==> Displays users in a group
$ sudo lid -g telusko

 Suraj(uid=1003)
 Binzila(uid=1004)

==> Display user belong to which group 

 id Suraj
uid=1003(Suraj) gid=1003(Suraj) groups=1003(Suraj),1005(telusko)

==> Remove user from user group

$ id Suraj
uid=1003(Suraj) gid=1003(Suraj) groups=1003(Suraj),1005(telusko)

$ sudo gpasswd -d Suraj telusko
Removing user Suraj from group telusko

$ id Suraj
uid=1003(Suraj) gid=1003(Suraj) groups=1003(Suraj)
