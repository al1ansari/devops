Cloud Computing with AWS
=========================================

Infrastructure 
==============
==> The resources required to run our project/company(Machines, networks, storage, database, monitoring...)

==> We can maintain infrastructure in 2 ways
1) On-Prem infrastructure
2) Cloud infrastructure

On-Prem infrastructure
======================
==> Purchasing and maintaining all resources by our own 

==>Challenges/Limitations associated with on-prem infrastructure

   -> Lot of cost
   -> Scalability
   -> Security Issue
   -> Networking
   -> Availability
   -> Natural Disaster
     ----
     ----

==> To overcome challenges associated with on-prem infra we can prefer cloud computing


Cloud Computing
===============

==> Delivering IT resources over internet on-demand basis with "Pay As You Go" Model is referred as Cloud Computing


Advantages/benefits
===================
=> Pay as you go model
=> Security
=> Backup
=> Scalability 
=> Availability

Cloud Service Models
====================
1) IAAS : Infrastructure as a service
2) PAAS : Platform as a service
3) SAAS : Software as a service

IAAS : Infrastructure as a service
===================================
==> Provider will provide infrastructure 
   ex: Machines(servers), storage, network

We need to take care of platform and application

PAAS : Platform as a service
============================

==> Provider will provide ready made platform to run our app (Provider will take care of infrastructure and platform)
ex: AWS Elastic beanstalk

The provider handles the underlying infrastructure and the software environment. You just focus on your code/app

SAAS : Software as a service
=============================
==> Application + infrastructure + platform all will be maintained by provider

Provider will give their application to run our business

ex: Zoom, Google drive, Dropbox........

AWS Global Infrastructure
The AWS Cloud spans 120 Availability Zones within 38 Geographic Regions (as of 15th OCT 2025)

AWS global infrastructure is the most secure, reliable, and extensive cloud, providing diverse infrastructure solutions for running your applications anywhere.

It is recommended to use nearest region to create infrastructure
